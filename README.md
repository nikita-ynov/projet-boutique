## 📝 Description
Ce projet consiste en la création d'une application de boutique en ligne complète. L'objectif est de mettre en pratique les concepts de développement web (architecture MVC, gestion de base de données, authentification) au travers d'une plateforme de vente fonctionnelle.

### ✨ Fonctionnalités clés
- **Gestion du Catalogue** : Affichage des produits par catégories.
- **Panier d'achat** : Ajout, modification et suppression d'articles.
- **Espace Client** : Inscription, connexion et historique des commandes.
- **Administration** : Interface de gestion des produits et des stocks (CRUD).
- **Paiement** : Simulation du processus de commande.

## 🚀 Technologies utilisées
Voici les principaux outils et langages utilisés pour ce projet :

* **Frontend** : HTML5, CSS3 (Sass/Tailwind), JavaScript
* **Backend** : ExpressJs
* **Base de données** : MySQL / PostgreSQL
* **Outils** : Docker, Git, Composer/NPM

## 📦 Installation & Configuration

Suivez ces étapes pour lancer le projet localement :

1.  **Cloner le dépôt**
    ```bash
    git clone [https://github.com/nikita-ynov/projet-boutique.git](https://github.com/nikita-ynov/projet-boutique.git)
    cd projet-boutique
    ```

2.  **Installer les dépendances**
    ```bash
    # Si PHP/Composer
    composer install
    # Si Node.js/NPM
    npm install
    ```

3.  **Configurer les variables d'environnement**
    * Copier le fichier `.env.example` en `.env`
    * Configurer vos accès à la base de données.

4.  **Lancer le serveur**
    ```bash
    # Exemple (à adapter selon votre framework)
    symfony serve -d 
    # ou
    npm start
    ```
